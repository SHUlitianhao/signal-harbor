# A 股行业域热度识别与利好/利空判断方案

## 1. 文档目标

本文档用于定义一套行业域识别流程：把全球金融信息收集系统采集到的宏观、政策、产业、新闻和市场数据，转化为“哪些 A 股行业域近期值得重点研究”的排序结果。

本流程只回答四个问题：

- 最近哪些行业域变热？
- 哪些行业域可能出现利好或利空？
- 判断依据和证据链是什么？
- 后续应该重点观察哪些数据？

本流程不负责：

- 决定买哪只股票
- 把行业域内股票池解释为买入清单
- 设定持仓权重
- 直接生成交易指令
- 替代回测、风控和人工复核

## 2. 核心原则

- 区分“热门”和“利好”：热门只表示关注度上升，利好必须有政策、产业、财务、资金或价格确认。
- 区分“行业域识别”和“个股购买”：本流程只筛出值得进一步研究的行业域，后续再在域内筛选个股。
- 估值不是利好来源：便宜本身不是利好，高估也不一定立刻利空；估值主要用于判断性价比和交易风险。
- 所有结论必须保留证据链：政策原文、产业数据、市场数据、财报数据、新闻来源或研报变化。
- 所有信号加入时间衰减：越新的事件权重越高，旧新闻不能长期支撑高分。

## 3. 行业域如何划分

默认以申万二级行业作为主要评分单位，用申万三级、概念标签和产业链标签扩展行业边界。

```text
行业域 = 申万二级/三级行业 + 概念标签 + 产业链上下游 + 全球变量映射
```

行业域不等于单一申万一级行业。很多主题会跨多个一级行业，例如 AI 算力同时涉及通信、电子、计算机、电力设备和公用事业。

行业域映射表建议字段：

```text
domain_name
domain_description
sw_l1_list
sw_l2_list
sw_l3_list
concept_tags
upstream_tags
midstream_tags
downstream_tags
related_global_variables
key_high_frequency_data
evidence_keywords
```

示例：

```text
domain_name: AI算力与电力协同
sw_l1_list: 通信、电子、计算机、电力设备、公用事业
sw_l2_list: 通信设备、半导体、IT服务、电网设备、电力
sw_l3_list: 光模块、服务器、PCB、液冷、电网自动化、储能
concept_tags: AI算力、数据中心、液冷服务器、光通信、虚拟电厂
related_global_variables: 海外AI资本开支、GPU供给、数据中心用电、电价、铜价
```

## 4. 具体使用哪些数据

系统固定使用八类数据。每一类数据都要能落到字段，不能只保留模糊描述。

| 数据类别 | 具体数据 | 作用 |
|---|---|---|
| 行业分类 | 申万一级/二级/三级、中信行业、概念板块、产业链标签 | 定义行业域 |
| 全球变量 | 美债利率、美元指数、人民币汇率、大宗商品、海外科技资本开支、地缘事件 | 判断全球传导 |
| 政策事件 | 国务院、发改委、工信部、财政部、央行、交易所、地方政策、补贴、招标、监管 | 判断外部催化 |
| 产业高频 | 产品价格、库存、开工率、订单、排产、销量、出口、运价、装机量 | 判断供需变化 |
| 财务基本面 | 营收、利润、毛利率、ROE、现金流、库存、应收、合同负债、资本开支 | 判断景气质量 |
| 一致预期 | 利润预测上修、EPS 上修、评级变化、目标价变化、上调/下调家数 | 判断预期变化 |
| 资金流 | 成交额占比、ETF 份额、北向资金、融资余额、公募持仓、龙虎榜集中度 | 判断资金关注 |
| 价格行为 | 行业涨跌幅、相对沪深300收益、上涨家数占比、创新高占比、波动率、回撤 | 判断市场确认 |

行业域高频数据示例：

| 行业域 | 高频数据 |
|---|---|
| AI算力 | GPU/服务器订单、光模块价格、IDC上架率、液冷渗透率、数据中心用电、算力租赁价格 |
| 半导体 | 存储价格、晶圆厂开工率、设备订单、材料价格、进出口、国产替代进度 |
| 新能源 | 锂价、硅料价格、电池排产、装机量、库存、组件出口 |
| 新型电力系统 | 电网投资、特高压招标、储能招标、变压器出口、全社会用电量 |
| 机器人 | 工业机器人产量、减速器订单、伺服电机订单、人形机器人发布/量产节点 |
| 出海链 | 出口金额、人民币汇率、海外库存、运价、关税政策、海外订单 |
| 消费复苏 | 社零、客流、票房、酒店入住率、免税销售、白酒批价 |
| 地产链 | 新房成交、二手房成交、土地成交、建材价格、竣工面积 |
| 资源品 | 铜、铝、煤炭、原油、天然气、黄金、化工品价格和库存 |

## 5. 热门、利好和风险的计算

先判断热度，再判断方向。热门不等于利好。

### 5.1 第一阶段可编码评分规则

第一阶段只使用新闻、公开源、同事件归并、标签、实体、风险词和来源质量，不接行情、资金、财务、估值、回测或交易接口。

热度分 `attention_score` 满分 100：

| 评分项 | 分值 | 当前实现口径 |
|---|---:|---|
| 事件数量 | 0-25 | 统计窗口内命中行业域关键词的归并事件数 |
| 热度增速 | 0-20 | 当前窗口事件数相对上一窗口变化 |
| 来源广度 | 0-15 | 覆盖该行业域的不同来源数量 |
| 来源质量 | 0-15 | 根据 `quality_tier` 做权重，官方/交易所/RSSHub/媒体分层 |
| 同事件确认 | 0-15 | 同一事件被多个来源覆盖时加分 |
| 时间衰减 | 0-10 | 越新的证据权重越高 |

方向分：

```text
benefit_score = 正向关键词命中 + 正向事件数 + 多来源确认
risk_score = 风险关键词命中 + 风险事件数
domain_score = short_term_catalyst_score + continuity_score + benefit_score * 0.5 - risk_score * 0.8 - noise_penalty
```

第一阶段结论标签：

| 条件 | signal_direction | signal_level |
|---|---|---|
| 热度高，利好显著高于风险 | 利好 | 重点研究 |
| 热度高，风险显著高于利好 | 利空 | 风险较高 |
| 热度高但方向不明确 | 仅热门 | 仅热门待确认 |
| 热度中等 | 中性偏强 / 中性偏弱 | 继续观察 |
| 热度低 | 中性 | 暂无明显信号 |

`market_confirmation` 第一阶段必须明确显示为“未接入”，表示尚未接入行业指数、成交额、资金流、财务和一致预期数据，不能用新闻热度冒充市场确认。

```text
热度分 = 新闻/政策频率 + 成交额占比变化 + 研报覆盖变化 + 社交讨论变化 + 价格活跃度
```

```text
利好分 = 政策催化 + 产业供需改善 + 财务景气改善 + 一致预期上修 + 资金流入 + 价格确认
```

```text
风险惩罚 = 监管收紧 + 产品价格下跌 + 库存上升 + 预期下修 + 资金流出 + 估值拥挤 + 交易过热
```

v1 可采用简单 0-3 分制：

```text
0 = 无明显信号
1 = 弱信号，只有单一来源或弱变化
2 = 中等信号，有多个来源或连续变化
3 = 强信号，有明确事件且被数据确认
```

总分建议：

```text
domain_score = short_term_catalyst_score + continuity_score + benefit_score * 0.5 - risk_score * 0.8 - noise_penalty
```

时间衰减建议：

```text
7日内事件：权重 1.0
8-30日事件：权重 0.6
31-90日事件：权重 0.3
90日以上事件：默认不再支撑高分，只作为背景信息
```

## 6. 利好/利空判断标准

| 结论 | 判断标准 |
|---|---|
| 强利好 | 有明确催化，并且至少 2 个确认信号改善 |
| 一般利好 | 没有强催化，但至少 3 个维度改善 |
| 仅热门 | 新闻或成交明显升温，但产业、资金、财务或价格没有确认 |
| 中性 | 数据互相矛盾，无法判断方向 |
| 一般利空 | 至少 2 个维度恶化 |
| 强利空 | 负面政策、监管、价格崩塌或业绩下修，并被资金或价格确认 |

确认信号包括：

```text
产业数据改善
一致预期上修
资金流入
行业相对收益走强
财务数据改善
```

常见利好信号：

| 维度 | 简单判断标准 |
|---|---|
| 政策 | 出现明确支持、补贴、招标、产业规划、监管放松 |
| 全球变量 | 海外需求上升、资本开支增加、相关商品价格上涨、汇率有利 |
| 产业供需 | 产品价格上涨、库存下降、开工率提升、订单增加 |
| 财务 | 营收和利润改善，毛利率提升，现金流改善 |
| 预期 | 盈利预测上修，上调家数多于下调家数 |
| 资金 | 成交额占比上升，ETF/北向/融资流入 |
| 价格 | 行业相对沪深300超额收益为正，上涨家数占比提升 |

常见利空信号：

| 维度 | 简单判断标准 |
|---|---|
| 政策 | 监管收紧、补贴退坡、集采压价、限制出口、处罚 |
| 全球变量 | 海外需求下滑、关税或制裁升级、汇率不利 |
| 产业供需 | 产品价格下跌、库存上升、开工率下降、订单减少 |
| 财务 | 收入放缓，利润下滑，毛利率下降，库存或应收恶化 |
| 预期 | 盈利预测下修，下调家数明显增加 |
| 资金 | 成交额萎缩，ETF/北向/融资持续流出 |
| 价格 | 行业持续跑输大盘，下跌个股占比高 |

```text
domain_score

related_sw_l3
related_concept_tags
key_data_changes

```

行业域详情已增加“关联监控股票池 Top 10”，用于持续监控该方向是否延续，以及后续验证该方向是否真的产生超额收益。该股票池不是推荐买入列表。

建议输出字段：

```text
related_stocks_top10
  stock_code
  stock_name
  association_rank
  association_score
  match_reasons
  matched_industry_tags
  matched_concepts
  matched_keywords
  related_events
  evidence_refs
  monitoring_metrics
  updated_at
```

`match_reasons` 必须用可审计语言说明为什么选中这只股票，例如：

```text
所属申万二级行业与行业域匹配
命中行业域概念标签
新闻标题/正文多次共现行业域关键词
公司业务关键词与产业链环节匹配
同事件报道中被多来源提及
后续行情/资金/财务数据验证强于行业平均
```

当前 MVP 关联度规则：

| 评分项 | 作用 |
|---|---|
| 行业分类匹配 | 判断股票是否属于该行业域核心范围 |
| 概念标签匹配 | 判断是否属于该主题或产业链 |
| 新闻/事件共现 | 判断股票是否真实出现在该方向的近期事件中 |
| 业务关键词匹配 | 判断主营业务与产业链环节是否相关 |
| 来源质量 | 高质量来源提及权重更高 |
| 时间衰减 | 近期证据权重更高 |
| 风险扣分 | 监管、亏损、减持、制裁等风险降低监控优先级 |

当前配置位于 `config/stock_universe.example.json`，字段包括 `stock_code`、`stock_name`、`exchange`、`sw_l1`、`sw_l2`、`sw_l3`、`concept_tags`、`business_keywords`、`domain_ids` 和 `notes`。当前不接行情、资金、财务和回测数据，因此 `monitoring_metrics` 中的行情、资金、财务、估值显示“未接入”，超额收益验证显示“待验证”。

后续验证指标建议：

```text
stock_excess_return_vs_domain_index
stock_excess_return_vs_hs300
domain_index_excess_return_vs_hs300
turnover_change
volume_price_confirmation
drawdown
volatility
event_continuity
risk_event_count
```

该设计的核心目的不是选股交易，而是回答：

```text
这个行业方向是否持续升温？
与该方向最相关的股票是否同步走强？
强相关股票是否跑赢行业指数或沪深300？
新闻热度和市场表现是否相互验证？
如果方向退潮，哪些监控股票最先变弱？
```

典型输出：

```text
domain_name: AI算力与电力协同
signal_level: 强利好
signal_direction: 利好
main_catalysts: AI资本开支上行、算力和电力协同政策推进
positive_evidence: 光模块订单改善、数据中心用电上升、行业成交额占比提升
negative_evidence: 估值分位偏高、部分标的交易拥挤
next_observation_points: GPU供给、光模块价格、电网投资、数据中心审批
```

## 8. 建议重点跟踪的行业域

以下是研究域，不是买入建议，也不限定最终股票数量。

| 行业域 | 跟踪理由 | 主要风险 |
|---|---|---|
| AI算力与电力协同 | AI、数据中心、算力、电力需求形成产业链联动 | 估值高、交易拥挤、海外限制 |
| 半导体与自主可控 | 国产替代、设备材料、先进封装具备长期逻辑 | 周期波动、兑现慢、估值高 |
| 机器人与具身智能 | 新产业趋势明确，横跨机械、电子、AI | 商业化节奏不确定 |
| 新型电力系统 | 电网、储能、虚拟电厂受益于用电结构变化 | 部分环节产能过剩 |
| 低空经济与商业航天 | 政策催化强，基础设施逐步展开 | 订单兑现慢，概念股多 |
| 高端制造出海链 | 海外订单、汇率、供应链重构驱动 | 关税、地缘政治、海外需求下滑 |
| 消费复苏与服务消费 | 客流、旅游、免税、文娱数据可高频跟踪 | 居民收入预期弱 |
| 资源品与通胀链 | 商品供需、地缘风险、价格上涨驱动 | 商品价格反转 |

## 9. 关联监控股票池边界

本流程只负责识别行业域和提供监控样本，不负责个股购买。

本流程回答：

```text
最近哪些行业域变热？
哪些行业域可能出现利好或利空？
证据是什么？
下一步应该观察什么？
哪些股票与该行业域关联最密切，适合用来监控方向持续性？
```

本流程不回答：

```text
应该买哪只股票？
买多少只？
仓位是多少？
什么时候买入或卖出？
```

后续如果要从监控股票池进入交易研究，应另建独立流程，使用个股基本面、流动性、估值、动量、风险暴露、交易成本和回测表现等指标，并始终保留“非买卖建议”的边界。

## 10. 验证要求

后续实现至少做三类验证：

```text
行业域回测：
检验行业域分数是否能预测未来 20/60/120 日行业超额收益

事件回放：
检查系统是否能在政策、新闻、产业数据变化后识别行业域变化

误判检查：
检查是否把单条新闻、单日上涨、短期情绪误判为强利好
```

验收标准：

```text
读完本文档后，工程实现者可以直接设计行业域映射表、数据字段表、利好/利空规则、行业域排序结果和回测任务。
```

## 11. 默认假设

- 默认市场是 A 股。
- 默认以申万行业为主，中信行业、概念板块和产业链标签为补充。
- 默认本流程只做行业域识别，不做最终买入决策。
- 默认行业域是后续深入研究范围，不是持仓组合。
- 默认所有判断都必须保留证据链，并标注正面证据、负面证据和下一步观察点。
- 默认所有结果都需要经过回测、风控和人工复核后，才能进入量化交易流程。
