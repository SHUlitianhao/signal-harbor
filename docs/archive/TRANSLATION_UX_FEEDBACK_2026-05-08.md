# 2026-05-08 翻译体验反馈归档摘要

本文件是历史归档，不作为当前状态依据。当前翻译边界请读 `docs/CURRENT_STATE.md`、`README.md` 和 `docs/ARCHITECTURE.md`。

## 原始反馈结论

- 英文情报点击“翻译”后没有明显中文变化。
- 英文样本曾被误显示为“原文中文”。
- 普通用户不希望主导航存在独立“翻译”工作台。
- 期望最新流、搜索、详情和提醒默认中文优先，同时保留原文和证据链接。

## 已处理结果

- 后端会对缺少语言提示的内容做轻量语言判断，明显英文不再返回 `not_required`。
- 最新流、搜索、详情和提醒优先展示 `translated_title`、`translated_summary`、中文标签和中文风险提示。
- 单条翻译按钮会刷新同一 item 的列表、详情和提醒展示；失败或词典未命中时显示明确状态。
- 独立“翻译”主导航和运行页翻译维护模块已移除；词典状态/维护 API 保留为 internal maintenance。

## 仍保留的边界

- 当前翻译仍是本地词典/规则辅助，不是完整机器翻译。
- 不调用外部翻译 API、云模型或长文全文翻译。
- 后续优先接入本地大模型自动翻译能力，而不是恢复普通用户手工词典维护页。
