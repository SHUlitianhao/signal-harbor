# 2026-05-09 历史交接摘要

本文件是历史归档，不作为当前状态依据。当前状态请先读 `docs/CURRENT_STATE.md`。

## 保留结论

- Signal Harbor 定位为本机自托管、单用户、手机 PWA 可访问的投资与国际资讯情报收集器。
- RSSHub 是外部上游服务，Signal Harbor 只消费其输出的公开 RSS，不并入 RSSHub 的 Node/TypeScript 依赖。
- 推荐本机端口：Signal Harbor `8765`，RSSHub `1200`。
- RSSHub 建议用 Docker Compose 常驻；Signal Harbor 启动时可复制 `config/sources.local.example.json` 为 `config/sources.local.json`，并用 `SIGNAL_HARBOR_SOURCES_CONFIG=config/sources.local.json` 指向本地公开源配置。
