# 量化与行业域上下文摘要

## 当前定位

Signal Harbor 已从单纯“投资与国际资讯情报收集器”升级为“本机自托管投资情报与行业域热度识别系统”。行业域选择是后续最重要的突出功能，但当前阶段只做新闻/事件驱动的研究优先级，不输出直接买卖建议。

## 当前第一期能力

- 使用现有公开源、RSSHub、事件归并、来源质量、标签、实体、风险词和证据链。
- 根据 `config/industry_domains.example.json` 中的行业域映射计算行业域榜单。
- 根据 `config/stock_universe.example.json` 中的监控样本配置，在行业域详情中输出关联监控股票池 Top 10。
- 输出 `attention_score`、`benefit_score`、`risk_score`、`domain_score`、`signal_direction`、`signal_level`。
- PWA 默认第一屏为“行业域”，用于查看分数拆解、主要催化、风险提示、相关事件、关联监控股票池和原始证据 URL。

## 明确边界

- 第一阶段不接行情、资金流、财务、一致预期、估值、回测、券商接口或自动交易。
- `market_confirmation` 显示为“未接入”，不能把新闻热度当作市场确认。
- 行业域结论只表示“重点研究 / 继续观察 / 仅热门待确认 / 风险较高”等研究优先级。
- 关联监控股票池只表示研究监控样本，不表示交易列表；每只股票必须保留关联理由、命中标签、相关事件和证据 URL。

## 后续扩展方向

1. 行业行情确认：行业指数相对收益、成交额占比、上涨家数占比、创新高比例。
2. 资金数据：ETF 份额、融资余额、北向资金、成交集中度。
3. 产业高频：商品价格、库存、开工率、订单、招标、出口。
4. 财务与预期：营收、利润、毛利率、盈利预测上修/下修。
5. 股票池验证：个股相对行业指数收益、个股相对沪深300收益、回撤、波动率和风险事件。
6. 规则稳定后再考虑可选本地模型辅助解释，但不替代证据链。
